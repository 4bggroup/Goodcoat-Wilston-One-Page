GOODCOAT — WILSTON PAINTING WEBSITE / CONCEPT 02

OPEN THE WEBSITE
Open Goodcoat_Wilston_One_Page.html in Chrome, Edge, Safari or Firefox.
The standalone file includes every image, style and interaction. No internet
connection or installation is needed to view it.

EDIT OR HOST THE WEBSITE
The editable-website folder contains index.html and an assets folder.
Keep them together. Upload the folder contents to a static web host.

INCLUDED
New blue and coral visual identity, new people, seven newly generated images,
30 service examples across six service categories, responsive navigation,
image gallery, colour palette selector, FAQs, a three-step enquiry builder,
live project summary, request copy/download and reduced-motion support.

ENQUIRY BEHAVIOUR
This is a reviewable design concept. The enquiry form validates the request
and prepares text for copying or download. It does not send email, store
customer information remotely, or confirm an appointment. Add the client's
chosen enquiry destination or backend before using it for live enquiries.

BRANDING AND CONTENT
Goodcoat is sample branding. People and properties are illustrative generated
images, not genuine staff or completed project photographs. No reviews,
ratings, licence claims or business history have been invented. Confirm the
client's service list, business details and trading name before launch.

DESIGN DIRECTION
The previous Stillwell concept used cream, green and serif typography.
This version uses bold blue, warm coral, large sans-serif headings, a more
direct visual rhythm and a new painting team. Target area: Wilston, Brisbane.
