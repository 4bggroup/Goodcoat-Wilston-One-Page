GOODCOAT — GITHUB PAGES READY

1. Extract this ZIP on your computer.
2. Upload index.html and the assets folder directly into the repository root.
   Keep the assets folder intact. Do not upload the ZIP itself as the website.
3. In the GitHub repository, open Settings > Pages.
4. Under Build and deployment select Deploy from a branch.
5. Choose main and /(root), then Save.
6. Open the website link shown on the Pages settings screen after deployment.

The entry file is now root-level index.html. There is no extra outer folder.
All seven images use relative assets paths, so repository subpaths are supported.

The enquiry form prepares a request for review/copy/download. It does not
send email or confirm a visit. Branding and imagery are illustrative concept
content, as in the original website.
